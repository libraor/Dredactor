# Dredactor Web 界面

基于 Streamlit 的 Dredactor Web 界面，提供图形化的 Word 文档脱敏和恢复功能。

## 功能特性

- **文档脱敏**：上传 Word 文档，选择脱敏模式，执行脱敏
- **脱敏映射与恢复**：支持保存脱敏映射，后续可恢复原始敏感信息
- **规则管理**：查看和搜索预置的脱敏规则
- **实时反馈**：显示处理进度、统计信息和处理结果
- **文件下载**：直接在浏览器中下载处理后的文件

## 安装

```bash
# 安装依赖
pip install -r ../requirements.txt

# 或者单独安装 web 相关依赖
pip install streamlit
```

## 启动

```bash
# 使用 run.py 启动（推荐）
python web/run.py

# 或者直接启动 streamlit
streamlit run web/app.py
```

启动后，在浏览器中访问：http://localhost:8501

## 使用指南

### 1. 文档脱敏

1. 在侧边栏选择"文档脱敏"页
2. 点击"上传 Word 文档"按钮，选择 `.docx` 文件
3. 配置脱敏选项：
   - **脱敏模式**：选择 mask（遮蔽）、replace（替换）或 partial（部分显示）
   - **替换文本**：在 replace 模式下，指定替换文本
   - **覆盖规则默认模式**：启用后全局应用选择的模式
   - **保存脱敏映射**：勾选后可后续恢复原始信息
4. 点击"执行脱敏"按钮
5. 查看处理结果：
   - 脱敏总数
   - 处理时间
   - 规则使用情况
6. 下载处理后的文件：
   - 脱敏文档
   - 映射文件（如果选择了保存映射）

### 2. 文档恢复

1. 在侧边栏选择"文档恢复"页
2. 上传脱敏后的文档（`.docx` 文件）
3. 上传映射文件（`.json` 文件），或使用包含映射 ID 的标准文件名格式
4. 点击"恢复文档"按钮
5. 下载恢复后的文档，原始敏感信息将被恢复

### 3. 规则管理

1. 在侧边栏选择"规则管理"页
2. 查看所有预置规则：
   - 规则名称和描述
   - 启用/禁用状态
   - 模式（mask/replace/partial）
   - 正则表达式
3. 使用搜索框过滤规则

### 4. 关于

查看项目信息、版本号和 GitHub 链接。

## 技术栈

- **Streamlit**：Python Web 应用框架
- **python-docx**：Word 文档处理
- **Dredactor 核心库**：脱敏引擎、规则管理、文档解析等

## 注意事项

1. **文件大小限制**：Streamlit 默认限制上传文件大小为 200MB
2. **本地处理**：所有处理在本地进行，不上传到任何服务器
3. **映射文件保管**：下载的映射文件请妥善保管，后续恢复时需要
4. **文件名格式**：保存映射时，脱敏文件名格式为 `xxx_redacted_[MAP_ID].docx`

## 故障排除

### 端口冲突

如果端口 8501 被占用，可以使用其他端口：

```bash
streamlit run web/app.py --server.port 8502
```

### 模块找不到

确保在项目根目录下运行：

```bash
cd /path/to/Dredactor
python web/run.py
```
